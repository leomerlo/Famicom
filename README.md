# Adiviná che

Juego tipo *Guess Up* en castellano rioplatense. Poné el celu en la frente, tus amigos te dan pistas: inclinar hacia abajo = acertó, hacia arriba = pasa.

- Categorías: Comidas, Farándula Argentina, Películas, Personajes, Animales (editá `js/data.js` para sumar cartas).
- PWA instalable y 100 % offline (service worker + manifest).
- Sin build: es HTML/CSS/JS estático. En Vercel, importá el repo como proyecto "Other" (sin build command, output = raíz).

Local: `npx serve .` (los sensores requieren HTTPS o localhost).
